# Interface walkthrough

[Watch or download the two-minute video](walkthrough.mp4) — H.264, 1280×720, without spoken narration.

It covers an everyday parenting concern, a brief plan and check-in, privacy controls, conversation reset, crisis escalation and the Urdu interface.

The recording uses predefined example responses. It illustrates the interface and is separate from the [live Gemini evaluation](EVALUATION.md). The application itself uses the server-side Gemini key configured in [START_HERE.md](../START_HERE.md).
